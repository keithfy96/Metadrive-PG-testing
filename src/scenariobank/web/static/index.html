One picture per scenario type, drawn at seed 0 by scenariobank examples. The arrow is where the car starts, so the picture says which way the route goes and not just what the road looks like. Click the ones you want, say how many of each, and generate.

Or compose a road by hand

Any string of the fifteen blocks, an exit rule and a seed, drawn by scenariobank inspect --block-seq exactly as a terminal would. It is a preview until you add it — the picture goes to the studio's scratch, and only Add to bank writes anything, into a scenario type named after the road and the rule. A road MetaDrive will not build is refused in MetaDrive's own words.

Read the exits asks the other question about the same road, with scenariobank sockets: every arm its last block offers, and what each of the five exit rules picks from them — including the rules that pick nothing. That is what to press when a draw is refused, and how a scenario type's destination was chosen in the first place.

        thing this screen exists to make visible.

The destinations reference

      

        Where every scenario type's route ends, at every seed, and how alike the roads behind
        them are — docs/reference/destinations.md, written by
        scenariobank destinations. It is checked in, so this is the document as it
        was last measured. Re-measure it after a MetaDrive bump: a figure nobody re-measures is
        a figure nobody can trust, and a change in block geometry has no other way to become
        visible.
